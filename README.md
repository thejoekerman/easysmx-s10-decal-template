# S10 Decal Insert Template

This is the print-at-home version of a custom faceplate for the EasySMX S10.

The EasySMX S10 ships with a frosted, magnetically attached faceplate. This template lets you put any artwork *underneath* that faceplate: print it, cut it out, drop it in, snap the plate back on. No adhesive, no permanent modifications, and you can swap the artwork whenever you feel like it.

## What you need

- A printer (any home printer works; color if you want color)
- **Thin** paper — regular printer paper, not cardstock. Thin paper follows the faceplate recess's curve; cardstock wrinkles.
- A hobby knife (X-Acto style) with a fresh blade, or a good pair of small scissors
- About 20 minutes

## How to print

> **⚠️ Print at 100% / actual size. Do NOT use "fit to page" or any scaling option — it silently shrinks the template and the decal won't fit.**

The template includes a **10 cm scale bar**. Before cutting anything, measure it with a ruler. If it doesn't measure 10 cm, your print scaled — print again at 100%. It doesn't need to be accurate down to the fraction of a mm though.

## How to cut

1. Cut the **inner holes first** (face buttons, d-pad openings), then the outer contour. Cutting inside first keeps the paper stable while you work.
2. Use a cutting mat if you have one — a self-healing hobby mat is ideal.
3. Place the cutout inside the controller's faceplate recess, then snap the frosted plate on top. Done.

## File guide

| File | Use it when... |
| --- | --- |
| `assets/template.pdf` | You just want to print it. Open, print at 100%, done. |
| `assets/template.svg` | You want to edit the template, or you own a cutter plotter (Cricut / Silhouette) — this file cuts directly. |
| `assets/template.png` | Your setup fights PDFs. Print at 300 DPI, scale 100%. |
| `assets/template.af` | You use Affinity (free) and want the full working source file with named layers. |
